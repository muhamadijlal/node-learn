# Roadmap Belajar Node.js

Setiap folder = 1 topik. Buka `PANDUAN.md` dulu buat baca materinya, lalu kerjakan `SOAL.md` di file `latihan.js` yang sudah disiapkan.

1. `01-node-basics` — process, argv, global object
2. `02-modules` — CommonJS & ES Modules
3. `03-npm-package` — package.json, install package, npm scripts
4. `04-file-system` — fs sync/async/promises
5. `05-events` — EventEmitter
6. `06-async` — callback, Promise, async/await, event loop
7. `07-http-server` — bikin REST API pakai modul `http` bawaan
8. `08-streams` — Readable/Writable/Transform stream
9. `09-error-handling` — try/catch async, uncaughtException, debugging
10. `10-express-bonus` — migrasi ke Express.js

Kerjakan berurutan. Kalau stuck di soal, tanya saya — jangan lihat jawaban duluan (memang belum saya sediakan jawabannya di sini supaya kamu latihan mikir sendiri).
